## 🚀 Getting Started

Clone the repository

```bash
git clone https://github.com/OmerP14/omerpehriz-portfolio.git
```

Install dependencies

```bash
npm install
```

Run the development server

```bash
npm run dev
```

Open

```
http://localhost:3000
```
